# Care Continuity

Care Continuity is a future application concept under the broader Continuity Platform direction.

The canonical conceptual application definition is captured in [Care Continuity Application Definition](care-continuity-application-definition.md).

It is being used to pressure-test the candidate Shared Continuity Foundation across a distinct application with different authority, language, users, actions, and obligations.

No Care Continuity application implementation currently exists in this repository.
