# Clinical Continuity

Clinical Continuity is the implemented application in this repository. The approved application-level direction is captured in [Clinical Continuity v0.1](clinical-continuity-v0.1.md).

OT is the current implemented configuration. The repository contains OT-specific reasoning vocabulary, workflows, and clinical concepts that should not be assumed portable without validation.

Detailed implementation references remain in the architecture, clinical-model, UX, and implementation documentation. This README marks the application layer in the authority hierarchy and points to the current approved application direction.
